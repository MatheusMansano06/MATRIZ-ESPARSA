Operação 1 — Cadastrar Aeroporto
Usuário digita o código IATA e o nome da cidade. O aeroporto vai para o vetor dinâmico do grafo.

1
main.c
op_cadastrarAeroporto(g)
Lê o código IATA com lerString(), converte para maiúsculas com maiusculas(), lê o nome da cidade. Valida que nenhum campo está vazio. Depois repassa para aeroporto.c.
lerString("Codigo IATA: ", codigo) → "gru" maiusculas(codigo) → "GRU" lerString("Cidade: ", cidade) → "Sao Paulo"
→ chama cadastrarAeroporto(g, "GRU", "Sao Paulo")
2
aeroporto.c
indiceAeroporto(g, "GRU")
Busca linear no vetor para ver se "GRU" já existe. Se retornar >= 0, o aeroporto já está cadastrado — falha com mensagem. Se retornar -1, pode continuar.
for i in 0..quantidade: if aeroportos[i].codigo == "GRU" → return i (já existe!) return -1 (pode cadastrar)
→ retorna -1 (não existe), continua em cadastrarAeroporto()
3
aeroporto.c
expandirVetor(g) — só se o vetor estiver cheio
Se quantidade == capacidade (vetor lotado), dobra o tamanho com realloc. Se realloc falhar, retorna 0 e o vetor original fica intacto. Caso o vetor não esteja cheio, este passo é pulado.
novaCapacidade = capacidade * 2 → 10 → 20 → 40... realloc(aeroportos, novaCapacidade * sizeof(Aeroporto))
→ vetor expandido (ou não era necessário)
4
aeroporto.c
cadastrarAeroporto() — copia os dados
Pega o ponteiro para o próximo slot vazio do vetor e copia código e cidade com strncpy (seguro: nunca passa do tamanho máximo). Incrementa quantidade.
a = &aeroportos[quantidade] ← próximo slot vazio strncpy(a->codigo, "GRU", 7) ← copia com limite strncpy(a->cidade, "Sao Paulo", 63) quantidade++ ← agora tem +1 aeroporto [OK] Aeroporto GRU cadastrado.
→ retorna para main() → menu aparece de novo

aeroporto.c

Converte os códigos em índices numéricos. O índice é o que a matriz usa como linha/coluna. Se qualquer um retornar -1, o aeroporto não existe e falha.
indiceAeroporto("GRU") → 0 (posição no vetor) indiceAeroporto("CNF") → 1 (posição no vetor) orig=0, dest=1 → voo vai na célula (linha 0, coluna 1)

3
matriz_esparsa.c
buscarElemento(m, 0, 1)
Checa se já existe um voo na rota GRU→CNF (célula linha 0, coluna 1). Se existir, não pode inserir outro na mesma célula — a matriz guarda só um dado por célula.
buscarCabecalho(linhas, 0) → acha cabeçalho da linha 0 percorre nós até coluna == 1 → NULL (célula vazia, pode inserir)
→ retorna NULL (livre), vai para inserirElemento()
4
matriz_esparsa.c
buscarOuCriarCabecalho(&linhas, 0)
Garante que existe um cabeçalho para a linha 0. Se não existir, cria e insere na lista de cabeçalhos em ordem crescente.
linhas: [cab0] ← criado agora primeiro → NULL (ainda sem nós)
→ faz o mesmo para a coluna 1
5
matriz_esparsa.c
inserirElemento() — aloca e encadeia o nó
Aloca o nó e copia o dado (struct Voo com numero=101) usando memcpy. Encadeia na lista da linha (ordenado por coluna) E na lista da coluna (ordenado por linha).
No *novo = malloc(sizeof(No)) novo->dado = malloc(sizeof(Voo)) ← 4 bytes memcpy(novo->dado, &voo, sizeof(Voo)) ← copia {numero=101} Lista da linha 0: [cab0] → [No(0,1,voo101)] Lista da coluna 1: [cab1] → [No(0,1,voo101)] ↑ mesmo nó nas duas listas!
→ retorna 1 (sucesso) → [OK] Voo 101 cadastrado
Operação 3 — Remover Voo
Usuário informa só o número do voo. O sistema busca em toda a matriz e remove a aresta.

aeroporto.c

1
main.c
op_removerVoo(g)
Lê apenas o número do voo. O enunciado pede remoção só pelo número — sem precisar saber origem e destino.
lerInteiro("Numero do voo: ") → 101
→ chama removerVoo(g, 101)
2
aeroporto.c
removerVoo() — varre toda a matriz
Como não sabe em qual rota está o voo 101, percorre todas as linhas (todos os aeroportos) chamando primeiroDaLinha() e comparando o número de cada voo.
for i = 0 até quantidade-1: no = primeiroDaLinha(matriz, i) ← entra na linha i while no != NULL: voo = (Voo*) no->dado if voo->numero == 101: dest = no->coluna ← salva ANTES de remover! removerElemento(i, dest) ← próximo passo return 1
→ achou voo 101 na linha 0, coluna 1 → chama removerElemento()
3
matriz_esparsa.c
removerElemento(m, 0, 1)
Desencadeia o nó da lista da linha E da lista da coluna. Depois libera o dado interno e o próprio nó. A ordem importa: primeiro ajustar ponteiros, depois liberar memória.
— Desencadeia da linha 0 — cab0->primeiro = no->proxLinha (era o único nó, fica NULL) — Desencadeia da coluna 1 — cab1->primeiro = no->proxColuna (era o único nó, fica NULL) free(no->dado) ← libera os 4 bytes do Voo free(no) ← libera o nó
→ chama removerCabecalhoSeVazio() para linha 0 e coluna 1
4
matriz_esparsa.c
removerCabecalhoSeVazio()
Verifica se a linha 0 e a coluna 1 ficaram sem nenhum nó. Se ficaram vazias, remove os próprios cabeçalhos para não deixar cabeçalhos fantasmas consumindo memória.
cab0->primeiro == NULL → remove cab0 da lista de linhas cab1->primeiro == NULL → remove cab1 da lista de colunas [OK] Voo 101 (GRU -> CNF) removido.

Operação 5 — Listar Trajetos entre dois Aeroportos (DFS)
A operação mais complexa. Usa busca em profundidade para encontrar TODOS os caminhos possíveis, incluindo com escalas.
main.c
aeroporto.c
matriz_esparsa.c
1
main.c
op_listarTrajetos(g)
Lê código de origem e destino, repassa.
orig = "GRU" (índice 0), dest = "BSB" (índice 3)
→ chama listarTrajetos(g, "GRU", "BSB")
2
aeroporto.c
listarTrajetos() — prepara o estado da DFS
Valida os aeroportos. Aloca dinamicamente dois arrays com tamanho igual ao número de aeroportos: visitados[] (para não entrar em ciclos) e caminho[] (para guardar o trajeto atual). Marca GRU como visitada e coloca no caminho.
visitados = calloc(5, sizeof(int)) → [0,0,0,0,0] caminho = malloc(5 * sizeof(int)) → [?,?,?,?,?] visitados[0] = 1 ← GRU marcada como visitada caminho[0] = 0 ← GRU entra no caminho profundidade = 1
→ chama dfs(g, &st, atual=0, destino=3)
3
aeroporto.c
dfs() — caso base e recursão
Função recursiva. Dois casos: (1) chegou ao destino → imprime o caminho acumulado. (2) ainda não chegou → para cada vizinho não visitado, entra nele e chama dfs() de novo. Ao voltar, desfaz a escolha (backtracking) para tentar outro caminho.
dfs(atual=GRU=0, destino=BSB=3) vizinhos de GRU: CNF(1), GIG(2) ← lidos da linha 0 da matriz → tenta CNF (não visitado): visitados[1]=1, caminho=[GRU,CNF], prof=2 dfs(atual=CNF=1, destino=BSB=3) vizinhos de CNF: GIG(2), GRU(0), SSA(4) → tenta GIG (não visitado): visitados[2]=1, caminho=[GRU,CNF,GIG], prof=3 dfs(atual=GIG=2, destino=BSB=3) vizinhos de GIG: CNF(1), GRU(0) → CNF já visitado, GRU já visitado → sem saída profundidade--, visitados[2]=0 ← BACKTRACK → tenta GRU → já visitado, pula → tenta SSA (não visitado): caminho=[GRU,CNF,SSA], prof=3 dfs(atual=SSA=4, destino=BSB=3) vizinhos de SSA: CNF(1) → já visitado → sem saída BACKTRACK BACKTRACK de CNF → tenta GIG (não visitado): visitados[2]=1, caminho=[GRU,GIG], prof=2 dfs(atual=GIG=2, destino=BSB=3) vizinhos: CNF(1), GRU(0) → CNF → dfs → ... → sem saída → BACKTRACK → GRU → já visitado BACKTRACK → Resultado: nenhum trajeto GRU→BSB encontrado diretamente
→ retorna para listarTrajetos()
4
aeroporto.c / matriz_esparsa.c
primeiroDaLinha() — dentro da DFS
A cada chamada de dfs(), ela chama primeiroDaLinha() para entrar na linha do aeroporto atual e percorre os vizinhos com no->proxLinha. É aqui que a matriz esparsa é consultada a cada passo da busca.
→ cada vizinho leva a uma nova chamada recursiva de dfs()
5
aeroporto.c
listarTrajetos() — libera memória
Depois que a DFS termina, libera visitados[] e caminho[] que foram alocados dinamicamente. Sem isso, vazamento de memória a cada chamada.
free(st.visitados) free(st.caminho) → retorna para main()
Destruição — Liberando toda a memória
Quando o usuário digita 0 para sair, o programa libera tudo que foi alocado antes de encerrar.
main.c
aeroporto.c
matriz_esparsa.c
1
main.c
main() — usuário digita 0
O loop do-while detecta opcao==0 e sai. main() então chama destruirGrafo() para liberar toda a memória antes de retornar EXIT_SUCCESS.
→ chama destruirGrafo(g)
2
aeroporto.c
destruirGrafo(g)
Libera em ordem: primeiro a matriz (que libera todos os nós internamente), depois o vetor de aeroportos, depois a struct Grafo. A ordem é importante porque a matriz referencia índices do vetor.
destruirMatriz(g->matriz) ← 1º: libera todos os voos free(g->aeroportos) ← 2º: libera o vetor de aeroportos free(g) ← 3º: libera a struct Grafo
→ chama destruirMatriz()
3
matriz_esparsa.c
destruirMatriz() — 1ª passagem: pelas linhas
Percorre cada cabeçalho de linha. Para cada linha, percorre todos os nós via proxLinha. Para cada nó: libera o dado interno (free(no->dado)) e depois o nó (free(no)). Por fim libera o cabeçalho da linha.
cabLin = linhas (cabeçalho da linha 0) no = cab0->primeiro while no != NULL: prox = no->proxLinha ← salva próximo ANTES de liberar free(no->dado) ← libera o Voo free(no) ← libera o nó no = prox free(cab0) ← libera o cabeçalho cabLin = próximo cabeçalho de linha...
→ todos os nós liberados → agora libera cabeçalhos de coluna
4
matriz_esparsa.c
destruirMatriz() — 2ª passagem: pelas colunas
Libera apenas os cabeçalhos de coluna. Os nós já foram liberados na 1ª passagem — não tenta liberá-los de novo (double free causaria crash).
cabCol = colunas while cabCol != NULL: prox = cabCol->prox free(cabCol) ← só o cabeçalho, nós já foram liberados cabCol = prox free(m) ← libera a struct MatrizEsparsa
→ retorna para destruirGrafo() → retorna para main() → programa encerra
